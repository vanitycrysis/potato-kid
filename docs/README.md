## The archive

`archive/` holds documents that were true when written and are kept for their detail. Nothing in it is an instruction.

| File | What it was |
|---|---|
| `archive/design-doc.md` | The owner's original concept for the game |
| `archive/GUI_MVP.md` | Codex's detailed UI specification, in rounds (code comments cite it as "GUI_MVP §n"; `UI.md` says which sections are current) |
| `archive/ART_AUDIO_PLAN.md`, `archive/ASSETS.md` | Codex's art and audio plans and its asset contract, in rounds. `ART.md` has the current rules |
| `archive/ROSTER_PLAN.md`, `archive/roster-mvp.json` | The plan for the first 64 kids and the route to about 500 |
| `archive/ENGINEERING_PLAN.md`, `archive/ENGINEERING_REVIEW.md`, `archive/PROJECT_PLAN.md` | The plans approved at gate 1 |
| `archive/CODEX_DELIVERY_NOTES.md` | What each Codex delivery contained, moved out of `DECISIONS.md` |
| `archive/TASKS_2026-10.md` | The task board up to the fourth gate-4 round, with every pull request number |
| `archive/HANDOFF_2026-10-29.md` | The previous handoff |
| `archive/briefs/` | Briefs written for Codex |
